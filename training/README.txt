ОБУЧЕНИЕ МОДЕЛИ ПРЕДСКАЗАНИЯ ГИПОКСИИ ПЛОДА  (TinyTCN, best_fold0.pt)
===========================================================================

─────────────────────────────────────────────────
1. СТРУКТУРА ДАННЫХ
─────────────────────────────────────────────────
training/
  hypoxia/   — 30 случаев гипоксии
    <case_id>/
      bpm/        *_1.csv   (ЧСС плода)
      uterus/     *_2.csv   (маточные сокращения)
  regular/   — 98 нормальных случаев
    <case_id>/
      bpm/        *_1.csv
      uterus/     *_2.csv

Каждый CSV: столбцы time_sec, value (нерегулярная частота дискретизации ~7.87 Гц).

─────────────────────────────────────────────────
2. ПРЕДОБРАБОТКА ДАННЫХ
─────────────────────────────────────────────────
Шаг 1 — Загрузка и объединение сегментов.
  Для каждого случая все CSV-файлы канала bpm (*_1.csv) и uterus (*_2.csv)
  считываются и конкатенируются в хронологическом порядке (sort по имени).

Шаг 2 — Ресэмплинг до 1 Гц.
  Исходный сигнал имеет нерегулярные временны́е метки. Линейная интерполяция
  (numpy.interp) переводит его на равномерную сетку с шагом 1 с.

Шаг 3 — Клиппинг физиологических значений.
  ЧСС:   [50, 210] уд/мин
  TOCO:  [-5, 100] усл. ед.
  Отсекает артефакты оборудования за пределами физиологической нормы.

Шаг 4 — Скользящие окна 20 минут (1200 точек).
  Stride = 5 минут (300 точек) — data augmentation за счёт перекрытия.
  Если запись короче 1200 точек, она дополняется (edge-padding) до нужной длины
  при условии, что она занимает не менее 50% окна.

Шаг 5 — Z-нормализация (per-window).
  Каждый канал независимо нормализуется: x_z = (x - mean) / std.
  При std < 1e-6 принимается std = 1 (защита от константных сегментов).

Шаг 6 — Стэкинг каналов.
  Финальный тензор: shape (2, 1200), channel 0 = FHR, channel 1 = TOCO.

─────────────────────────────────────────────────
3. АУГМЕНТАЦИИ ПРИ ОБУЧЕНИИ
─────────────────────────────────────────────────
  • Временной сдвиг ±5 точек (numpy.roll) — p=0.5
  • Гауссовский шум N(0, 0.02) — p=0.5
  • Масштабирование амплитуды TOCO × U[0.7, 1.3] — p=0.5
  • Масштабирование амплитуды FHR  × U[0.8, 1.2] — p=0.4

─────────────────────────────────────────────────
4. АРХИТЕКТУРА МОДЕЛИ (TinyTCN)
─────────────────────────────────────────────────
Temporal Convolutional Network с расширяющимися свёртками (dilated):

  Stem:    Conv1d(2 → 48, k=7)
  Block1:  ResidualBlock(48 → 48,  k=7, dilation=1)
  Block2:  ResidualBlock(48 → 96,  k=7, dilation=2)
  Pool2:   AvgPool1d(2)
  Block3:  ResidualBlock(96 → 96,  k=7, dilation=4)
  Block4:  ResidualBlock(96 → 192, k=7, dilation=8)
  Pool4:   AdaptiveAvgPool1d(1)
  Head:    Linear(192→96) → ReLU → Dropout(0.2) → Linear(96→1)

Выход: скалярный логит → сигмоид → вероятность гипоксии ∈ [0, 1].
Параметры: base=48 — точно соответствует best_fold0.pt в inference.

─────────────────────────────────────────────────
5. ПРОЦЕСС ОБУЧЕНИЯ
─────────────────────────────────────────────────
  • Разбивка:   Stratified K-Fold (k=5) по case_id (не по окнам).
                Это предотвращает утечку данных одного случая в обе выборки.
  • Лосс:       BCEWithLogitsLoss с pos_weight = n_negative / n_positive
                (~3.3 для текущего датасета) — борьба с дисбалансом классов.
  • Оптимизатор: AdamW (lr=3e-4, weight_decay=1e-4)
  • Scheduler:  CosineAnnealingLR (T_max=60, eta_min=1e-5)
  • Сэмплер:    WeightedRandomSampler — дополнительное балансирование батчей.
  • Early stopping: patience=15 эпох без улучшения AUC на val.
  • Метрика выбора чекпоинта: ROC-AUC на валидации.
  • Эпох: до 60 (с ранней остановкой).

      --out_dir . \
